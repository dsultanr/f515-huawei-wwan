# Ручной запуск и технические детали

Этот файл — для тех, кому не подходит приложение (нет возможности установить, или нужен
именно ADB напрямую). Обычному пользователю он не нужен — см. [README.md](../README.md).

## Ручной запуск по ADB (без приложения)

```bash
adb shell mkdir -p /data/local/tmp/wwan
adb push scripts/wwan-up.sh scripts/dial.sh scripts/at.sh \
         modules/prebuilt/usbserialmerged2.ko modules/prebuilt/ppp_async.ko \
         tools/huawei-modeswitch \
         /data/local/tmp/wwan/
adb shell chmod 755 /data/local/tmp/wwan/*.sh /data/local/tmp/wwan/huawei-modeswitch

adb shell /data/local/tmp/wwan/wwan-up.sh --check     # диагностика, ничего не меняет
adb shell WWAN_APN=internet.beeline.kz /data/local/tmp/wwan/wwan-up.sh
adb shell /data/local/tmp/wwan/wwan-up.sh --system    # + интернет приложениям
```

APN оператора обязательно проверь заранее — без него дозвон не пройдёт (см.
`scripts/wwan.conf.example`).

## Как это устроено

`scripts/wwan-up.sh` идёт десятью стадиями (окружение → файлы → USB-устройство →
modeswitch → модуль usbserial → последовательные порты → PPP в ядре → SIM/регистрация →
дозвон → маршруты). **Каждая стадия сначала проверяет, что нужно сделать именно сейчас**:
если условие уже выполнено — стадия пропускается, если нет предпосылок для следующего
шага — скрипт останавливается с понятным сообщением и подсказкой, что делать, а не падает
где-то в середине с непонятной ошибкой. Повторный запуск всегда безопасен (идемпотентно):
можно жать «Включить» сколько угодно раз, в том числе на уже поднятой сети.

`--check` прогоняет все проверки в режиме "только посмотреть", ничего не меняя на
устройстве — полезно как первый шаг диагностики.

Ядро головы не поддерживает Huawei "из коробки" (`CONFIG_USB_SERIAL` не собран) и не
собран line discipline для PPP (`CONFIG_PPP_ASYNC`). Модули для обоих собраны отдельно —
см. [modules/README.md](../modules/README.md), если нужно пересобрать под другое ядро.

Модем в USB попадает в storage-режиме (`14fe` и т.п.) и не отдаёт AT/PPP-порты, пока его
не переключить одной SCSI-командой (то же самое, что делает `usb_modeswitch`, но без
самого `usb_modeswitch`, которого на голове нет) — см. [tools/README.md](../tools/README.md).

`--system` дополнительно донастраивает маршрутизацию так, чтобы интернет через модем
видели не только root/adb-команды, но и обычные приложения Android — в том числе когда
Wi-Fi выключен и никакой другой сети нет. Детали — в [app-network.md](app-network.md).

## Ограничения

- Всё runtime-only: после перезагрузки головы модули и PPP нужно поднимать заново
  (`wwan-up.sh` тем же вызовом). Автозапуска на BOOT_COMPLETED нет и не планировался.
- Если модем физически вынуть и вставить снова, режим `14fe` возвращается — `wwan-up.sh`
  сам это увидит на стадии 3 и вызовет modeswitch заново.
- `/` на этой прошивке read-only (dm-verity) — всё, что делает скрипт, это runtime-
  состояние ядра/сети, ничего не пишется на системный раздел.
